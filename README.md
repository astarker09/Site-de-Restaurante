# Cenário de Software
Sistema de Gestão de Restaurante, Cardápio e Pedidos

O cenário modela a operação essencial de um restaurante, abrangendo o atendimento feito pelos garçons nas mesas, a escolha de pratos e bebidas no cardápio, a gestão dos ingredientes de cada prato, a geração de pedidos e o registo dos respetivos pagamentos
